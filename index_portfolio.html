06
Feature Engineering pour la vision par ordinateur — CIFAR-10 Deep Learning

Travail individuel comparant trois représentations d'images (pixels bruts, HOG, features CNN extraites via MobileNetV2 pré-entraîné) et deux méthodes de sélection de features (Variance Threshold, Mutual Information) sur un sous-ensemble de CIFAR-10. Pipeline construit dans le strict respect des bonnes pratiques anti-data-leakage (split avant extraction, transformations apprises uniquement sur le train set). Meilleure configuration : features CNN + Mutual Information, réduction de 70% des features sans perte de performance et entraînement jusqu'à 16× plus rapide.

PythonTensorFlow/Kerasscikit-learnMobileNetV2 (CNN)scikit-image (HOG)
